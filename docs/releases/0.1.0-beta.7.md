# Vela 0.1.0-beta.7

macOS 14+、Apple Silicon（arm64）公开测试版。

- 稳定使用记录和供应商列表的列宽与表头对齐，避免长短内容、筛选和状态变化导致列间距跳动；窄窗口支持列表内横向滚动。
- 使用记录增加“昨天”筛选，Key 名称后展示该次请求实际执行倍率。
- 优化调度与模型映射的拖动排序动效。
- 修复展开设置时侧栏菜单上移，出站代理认证改为按需展开。

## 安装与升级

下载 DMG 安装，或在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

其他协议、隐私与功能边界沿用 [0.1.0-beta.6 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.6.md)。本版不提供 Intel、Windows 或 Linux 安装包。
