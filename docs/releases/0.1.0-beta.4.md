# Vela 0.1.0-beta.4

macOS 14+、Apple Silicon（arm64）公开测试版。

- 修复关闭使用记录实时刷新后，关闭前发出的旧查询仍可能插入新记录的问题。
- 优化进行中记录的高亮效果。
- 重整设置功能分类，方便查找网关、网络和应用偏好。
- 模型验证的多条样本出现完全重复数字序列，或仅截断长度不同时，结论显示“证据不足 / 无法判断”。详情保留原始候选、参考库内置信度和样本，并说明重复证据的原因；已有报告不追溯重判，可手动复测。

## 安装与升级

下载本版 DMG 后双击 Vela.app，选择安装并打开；也可在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

模型指纹仍是参考库内的统计线索，置信度不代表模型身份真实性。本版不承诺独立模型识别准确率或容量性能改善；其他协议、隐私与功能边界沿用 [0.1.0-beta.3 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.3.md)。不提供 Intel、Windows 或 Linux 安装包。
