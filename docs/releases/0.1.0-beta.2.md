# Vela 0.1.0-beta.2

macOS 14+、Apple Silicon（arm64）公开测试版。

- 修复供应商与 Key 配置交互、账户查询及窗口恢复后的信息刷新。
- 完善模型映射的上游模型选择和拖动排序。
- 同步价格后显示成功、部分失败或失败提示，区分目录更新与最近成功检查时间。
- 模型验证的创建操作归属检测计划页，检测计划改用表格展示。

波浪排序效果仍为独立交互小样，未接入本版。

## 安装与升级

下载 DMG 后双击 Vela.app，选择安装并打开；也可在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

协议支持、数据保护与已知功能边界沿用 [0.1.0-beta.1 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.1.md)。本版本不提供 Intel、Windows 或 Linux 安装包。
