# Vela 0.1.0-beta.9

macOS 14+、Apple Silicon（arm64）公开测试版。

- 重构供应商和使用记录列表的列宽分配：标准1200×800窗口下完整显示全部列，包含默认及240px侧栏；缩小到可读下限后仅在列表内部横向滚动。
- 供应商、Key及模型名称按内容需要分配宽度，百分比只限制上限；窗口放大时有限舒展，多余空间留在表格外侧。
- 筛选、翻页、刷新、记录插入和收尾期间保持列边界稳定；长名称和超宽余额在本列省略，保留完整内容提示及现有操作。

## 安装与升级

下载 DMG 安装，或在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

本次布局已通过实际App外壳的浏览器验收及独立MyGo原生WebView检查，使用隔离样例，未连接用户真实业务库。覆盖默认、放大和缩小窗口、长短名称及列宽稳定性。其他协议、隐私与功能边界沿用 [0.1.0-beta.8 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.8.md)。本版不提供 Intel、Windows 或 Linux 安装包。
