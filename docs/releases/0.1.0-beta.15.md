# Vela 0.1.0-beta.15

macOS 14 及以上，适用于 Apple Silicon Mac。

- 请求和响应正文改为独立压缩文件。使用记录和正文可分别设置保留天数和预览清理。
- 从旧版升级时，Vela 取得数据目录独占锁后自动备份原目录，再迁移保留期内的正文并缩容 SQLite。macOS 优先使用文件克隆，文件系统不支持时会复制文件。

## 升级与恢复

通过 DMG 替换应用，保留原数据目录。第一次打开时，网关会等迁移完成后再启动。旧库较大时请给迁移留出时间，也可在这段时间让客户端临时使用备用网关。

默认备份目录为 `~/Library/Application Support/Vela.before-body-migration`。迁移失败时，可重新打开新版继续。如果需要回退，退出新版，把当前 `Vela` 数据目录移到别处，将备份复制回同级的 `Vela` 目录，再启动旧版。恢复备份会恢复升级前的状态，升级后新增的数据仍在移出的目录里。

确认配置、用量和近期正文可读后，可自行移除备份。保留备份期间，系统仍会为旧数据库保留磁盘块。
