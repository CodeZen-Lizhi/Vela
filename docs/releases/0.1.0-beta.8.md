# Vela 0.1.0-beta.8

macOS 14+、Apple Silicon（arm64）公开测试版。

- 请求失败时展示更具体的原因：首次响应超时包含等待秒数，连接失败保留网络或 TLS 错误；详情摘要和执行链路补充上游 HTTP 状态、错误码及错误正文。
- 请求与响应视图明确区分未收到上游响应、空正文、未采集和正文过期；没有响应正文时不再误显示快照截断提示。
- 上游错误继续按现有规则脱敏，正文过期后不通过错误提示恢复展示。旧记录当时未保存的底层故障无法事后补回。
- 统一使用记录中 Key 实际执行倍率的显示格式。

## 安装与升级

下载 DMG 安装，或在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

本次修复已通过真实鉴权本机网关、隔离 SQLite 持久化及实际详情组件的浏览器验收；未重放用户历史故障请求。其他协议、隐私与功能边界沿用 [0.1.0-beta.7 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.7.md)。本版不提供 Intel、Windows 或 Linux 安装包。
