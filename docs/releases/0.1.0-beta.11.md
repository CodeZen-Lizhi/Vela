# Vela 0.1.0-beta.11

macOS 14+、Apple Silicon（arm64）公开测试版。

- 修复供应商和使用记录在宽窗口中整表居中、两侧留下大片空白的问题。表头、行分隔线和整行背景随表格铺满白框，剩余宽度由所有列按预算比例分配。
- 模型验证的验证结果、检测计划共用同一列宽分配逻辑，执行模型不再独占剩余空间。
- 名称显示上限与列布局宽度分开，长模型、供应商和Key名称保持省略及全文提示；按钮、字号和行高保持原尺寸。
- 正常窗口完整展示，低于各表可读下限后仅表格内部横向滚动。

## 安装与升级

下载 DMG 安装，或在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

布局检查使用实际App组件及隔离样例，覆盖正常、宽窗口和窄窗口；未连接用户真实业务库或付费上游。其他功能与隐私边界沿用 [0.1.0-beta.10 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.10.md)。本版不提供 Intel、Windows 或 Linux 安装包。
