# Vela 0.1.0-beta.5

macOS 14+、Apple Silicon（arm64）公开测试版。

- 开放“设置 → 数据管理 → 导入与导出”，在不同电脑复用完整模型与价格、供应商请求配置、上游 Key、模型映射与权限、调度策略及供应商顺序。
- 配置文件包含实际调用密钥、余额查询与 Key 信息查询所需的完整认证和配置，导入后无需重新填写。导出时设置至少 8 个字符的密码，导入时使用同一密码；文件加密保存，导入后使用目标电脑的本机密钥重新加密。
- 导入先校验并预览数量，可选择“覆盖相同配置”或默认的“保留原有、仅新增”。两种方式都保留使用记录、总览统计、验证报告、本机独有项、本机偏好和网关访问密钥。
- 重复导入不重复创建配置；密码错误、文件损坏、版本不支持、文件超限或写入中途失败时，原有数据保留。

## 安装与升级

下载本版 DMG 后双击 Vela.app，选择安装并打开；也可在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

请妥善保管导出文件与密码；密码遗失后无法恢复该文件。只接受正式 Vela v1 加密配置，不兼容旧原型的演示配置，也不提供整库备份恢复。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

其他协议、隐私与功能边界沿用 [0.1.0-beta.4 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.4.md)。本版不提供 Intel、Windows 或 Linux 安装包。
