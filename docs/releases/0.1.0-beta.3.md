# Vela 0.1.0-beta.3

macOS 14+、Apple Silicon（arm64）公开测试版。

- 修复持续返回数据的流式请求在累计达到超时值后被中断的问题；设置改为“流式空闲超时”，已有数值继续生效。
- 原生 compact 和 compaction_trigger 使用独立长等待，默认 20 分钟，显式请求超时优先；普通流式仍按空闲时间判断。
- 压缩结果必须完整有效；HTTP 不交付残缺检查点。已知有效压缩检查点复用原目标，原目标失效时明确拒绝。绑定仅在当前进程内有界保存，未知或过期摘要仍由上游验证。
- 请求详情改为双栏，完善内容复制，记住实时刷新开关。
- 统一列表表头和顶部消息提示，改善模型验证布局、线路添加和删除及校验定位。

## 安装与升级

下载本版 DMG 后双击 Vela.app，选择安装并打开；或在旧版设置中检查更新。更新会退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

本版已通过本地 HTTP/SSE/WebSocket 回归和源码检查；真实远端供应商与历史故障会话未完成新版组合实测。不提供 Intel、Windows 或 Linux 安装包。
