# Vela 0.1.0-beta.6

macOS 14+、Apple Silicon（arm64）公开测试版。

- 修复账户验证排队时缺少超时、界面持续等待的问题；超时后可重试。
- 供应商列表按内容动态分配列宽，设置最小与最大宽度，长名称和 Key 超出上限后省略并支持查看全文。
- 密码输入与访问密钥隐藏展示统一使用星号，修复 macOS WebView 密码遮罩显示为横线块的问题。
- 修复倍率来源、状态筛选、统计维度、外观、导入模式及调度策略等必选分段控件重复点击后取消选中的问题；取消排序等明确允许清空的操作保持可用。

## 安装与升级

下载本版 DMG 后双击 Vela.app，选择安装并打开；也可在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

配置导入导出及其他协议、隐私与功能边界沿用 [0.1.0-beta.5 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.5.md)。本版不提供 Intel、Windows 或 Linux 安装包。
