# Vela 0.1.0-beta.10

macOS 14+、Apple Silicon（arm64）公开测试版。

- 统一七个主页面的标题、内容区域和灰色留白；放大窗口时白框随可用空间扩展，切换菜单时保持外框边界一致。
- 列表加载和错误提示保留在白框内，避免状态变化推动整个外框；普通页面在标题下滚动，列表仅数据区滚动。
- 按实际文字、图标、模型标签和间距测量名称列，移除固定附加宽度，减少模型与供应商之间不必要的空白。
- 修复1049px常用窗口下使用记录仍需横滑的问题；更窄窗口仅表格内部横向滚动。
- 首次打开优先使用1200×800，屏幕不足时缩小；重启保留用户调整的窗口尺寸和位置，越界窗口收回屏幕工作区。

## 安装与升级

下载 DMG 安装，或在旧版设置中检查更新。升级会正常退出旧应用并短暂停止网关，保留配置和记录。

安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开如被阻止，请核对下载来源及 SHA256SUMS，再按系统隐私与安全性提示打开。

本次布局使用实际App组件及隔离数据，通过浏览器五组窗口尺寸和原生MyGo窗口检查；未连接用户真实业务库或付费上游。其他协议、隐私与功能边界沿用 [0.1.0-beta.8 说明](https://github.com/CodeZen-Lizhi/Vela/blob/main/docs/releases/0.1.0-beta.8.md)。本版不提供 Intel、Windows 或 Linux 安装包。
