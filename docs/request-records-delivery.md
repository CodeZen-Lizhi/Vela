- 使用记录导航、数据库内组合搜索/筛选、默认 20 条分页、五项整组摘要、模型/供应商折叠分析；未知消耗与已知零值区分。
- 实时默认关闭且不持久化；第一页可插入新记录，后续页固定插入快照；已展示活跃请求持续收尾，结束后重取相同快照中的筛选结果和总数；窗口恢复刷新。
- 现有调度、模型测试、模型验证真实 HTTP 出站均关联逻辑请求；逐次记录候选、重试/转移、熔断来源、HTTP 状态、脱敏头/正文。视频状态轮询单独标识，不误判为重试或重复收费。

- 价格规则在开始时固定，倍率按实际候选快照；四聊天协议缓存归一化、媒体 Token 分项及图片尺寸/像素档、视频实际秒数计价。缺少完整用量、价格或混合媒体缓存分维度时保持未知，尝试详情保留已知事实。
- 单条详情保留名称快照并另示当前名/已删除；长期统计使用稳定身份与当前名/删除前最后名。Key 累计按各次实际尝试分配，独立于逻辑请求累计。
- 正文从结束起 7 天、明细 30 天；启动和每小时到期清理。手动清理预览固定截止时间，确认后删除已结束明细，长期累计和配置独立保留。重启遗留活跃请求标为失败且最终上游结果未知。
