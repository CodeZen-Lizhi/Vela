# 请求正文独立存储

请求和响应快照是历史数据目录的主要空间来源。总览、供应商统计、查询、HTTP 头、费用和执行链路继续使用 SQLite。桌面应用为每个已结束请求保存一个 Zstandard 压缩 JSON 文件，使用 UTC 结束日期分目录，文件名包含结束毫秒和请求 ID。

正文写入先同步临时文件，再原子改名。文件读写失败单独提示，查询仍返回 SQLite 中可用的请求明细。正文可按文件名中的结束时间独立清理，即使 SQLite 明细已经删除。

升级时先逐条归档仍在原保留期内的旧正文，回读校验后再清除旧数据库中的正文。已校验的请求可跳过并继续迁移。首次升级压缩 SQLite 以归还空闲页，迁移期间需要额外磁盘空间，数据库文件与正文目录均属于恢复所需的数据。
