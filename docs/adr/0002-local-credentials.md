# 0002：本地凭据加密与保护边界

- 状态：已采纳
- 日期：2026-11-11

## 背景

Vela 在 GitHub 开源，不以付费 Apple 签名身份为使用前提。用户确认整体 PRD R53：本地保存、加密落盘，避免普通配置、日志及默认导出泄露凭据；接受无法抵挡取得当前用户权限的恶意程序。旧实现通过 MyGo Secrets 读取钥匙串，ad-hoc 构建更新可能重新要求访问授权。

## 决策

使用 Go 标准库 AES-256-GCM 和随机 nonce，复用供应商凭据的记录绑定语义。应用数据目录的专用 credentials 子目录权限为 0700，随机 32 字节主密钥和密文文件权限为 0600；写入密文先同步临时文件再原子替换。网关访问密钥与供应商加密主密钥由同一个存储实例串行读写，上游密文继续保存在 SQLite；可能含代理认证的全局、供应商及 Key 配置文档使用同一文件主密钥加密，旧 JSON 在初始化时迁移。供应商与 Key 配置在同一事务内迁移，失败回滚；不承诺擦除历史数据库页或备份中的旧明文。

旧版已接入的网关访问密钥按需迁移，不删除旧钥匙串项；成功或确认不存在后记录结果，后续版本读取本地文件。隔离验收目录不迁移日常钥匙串。钥匙串拒绝授权、文件损坏或主密钥缺失时拒绝覆盖，保留可重试或恢复的原数据。账户令牌与查询认证复用供应商主密钥和记录绑定语义加密。

2026-11-15 配置搬运补充：用户主动导出的配置包含完整上游调用、余额与 Key 查询认证，使用独立导出密码加密；采用每次随机 16 字节盐、PBKDF2-HMAC-SHA256（600000 次）派生 32 字节密钥，并复用 AES-256-GCM 与随机 nonce。密码不保存，版本与派生参数固定，错误密码或损坏包拒绝导入。文件不携带本机网关访问密钥或主密钥；目标机器解密后使用本机凭据存储重新加密，普通配置和日志继续不包含明文凭据。

## 影响与限制

数据库单独泄露不暴露 API Key；同时读取主密钥与密文可以解密。0600 隔离其他普通系统账户，不隔离同一用户运行的不同程序。本方案不采用固定密码、机器编号派生密钥或源码内置密钥，不宣称等价于系统钥匙串。旧版本不会读取新的凭据文件，回退旧包可能读到保留但已过时的旧钥匙串值。

不新增启动解锁步骤，不引入外部服务或依赖。配置搬运仅在导出、导入时输入文件密码；遗失密码无法恢复该文件。应用内自动更新签名、公证独立实施，不保证 Gatekeeper 或安装目录授权只发生一次。后续若需要应用级隔离，应重新评估系统凭据存储或用户解锁，不能靠隐藏密钥文件提升宣传等级。

## 验证

真实文件与应用服务测试覆盖加密落盘、文件权限、迁移重试、更新后重读、缺失主密钥与损坏密文时数据保留；桌面隔离验收覆盖实际绑定调用与重启。模拟的旧存储读取仅证明迁移分支，不证明真实系统弹窗次数。

2026-11-11 验证记录：Go 全量测试通过；受影响凭据、供应商、模型与桌面装配测试在 race 下通过，go vet 通过，Svelte 检查 0 错误/0 警告，MyGo App/DMG 构建通过。macOS 隔离 e2e 构建经真实 MyGo 绑定保存访问密钥、供应商 API Key 与含认证的代理配置，退出重启后重读一致、列表无 API Key 明文；数据库逻辑记录及文件扫描不含合成凭据明文。ego-browser 已核验设置页本机加密说明。迁移拒绝/重试与不再访问旧存储由回调测试覆盖；真实用户钥匙串弹窗次数、跨机 Gatekeeper 与自动更新发布仍未验证。本地验收证据位于 `.cache/credentials-acceptance/evidence.json`。
