## 依据与范围

以 Aether 的 `docs/tasks/11-07-desktop-rewrite/provider-management.md`、旧版业务代码和用户确认的新 UI 为依据。未明确修改的业务按旧版迁移。

本轮完成供应商配置、Key、模型关联/权限/有序映射及账户查询的 Go/MyGo + Svelte 闭环。原工作目录存在未提交基础实现，Worktree 复制其源码作为开发基线；原目录不变，因此本分支相对 HEAD 的全部差异并非都来自本轮。开发交付时尚未提交；本次按用户要求保留主分支已有实现并整合供应商代码，本地合并，不 push。

## 实现

- 供应商列表、搜索/状态/关联模型筛选、创建/编辑/启停/确认删除、右侧详情、首选 Key 和倍率摘要。
- Key 新增/编辑/启停/删除、后端复制完整凭据、全部/指定模型权限；名称和倍率来源独立，查询连接可复用供应商或单独配置。
- 模型关联、关联启停和有序映射工作台，保留操作范围；统一模型删除时通过外键清理从属关联、权限与映射。
- Sub2API、New API、兼容 API Key 和自定义 GET/POST 账户查询；原币种、现金/积分、订阅额度、本地月配额分别表达；New API 可选签到。
- 页面进入及恢复只读本地，主动刷新/配置保存/Key 来源保存按范围查询，全局设置控制定时查询。查询失败保留配置、旧值和最后成功时间；新建上游倍率失败保持未知，合法零倍率仍为零。
- Key 与查询配置同一事务保存，网络在事务与 Store 写锁外执行。在途配置变更或删除不会写回旧结果，单轮故障不永久终止定时刷新。
- 调用密钥、账户秘密及含认证的代理 URL 加密落库，页面读取仅掩码；供应商和 Key 分别解析有效出口。失去已有密文的主密钥时拒绝覆盖。
